# 면접 전형 결과 리포트

읽을 자료: get_values(interview.question.*: CONFIRMED · UNCONFIRMED · CONFLICT), 앞 전형 값, get_evidence(stage는 면접 전형).

## 섹션 구성 (한눈에 보기 → 영역마다 섹션 하나 → 확인할 점)

1. kpi: 면접 대상 · 합격 · 답변 기록률 지표
2. matrix: 지원자 × 질문 확인 상태
3. table: 앞 전형 점수와 면접 확인 수
4. evidence: 상충(CONFLICT) 사례와 아직 확인되지 않은 점

## 요약에 담을 것

앞 전형에서 확인할 점이 면접에서 확인됐는지, 상충이 있었는지. 마지막 전형이면 다음 전형 확인할 점은 쓰지 않는다.
