# 평가 전형 결과 리포트

읽을 자료: get_values(assessment.total, assessment.area.*), 앞 전형 결정(document.decision), get_evidence(stage는 평가 전형).

## 섹션 구성 (한눈에 보기 → 영역마다 섹션 하나 → 확인할 점)

1. kpi: 응시 · 합격 · 미응시 지표
2. distribution: assessment.total
3. radar 또는 bar: 합격자의 영역 점수 (만점이 같은 영역만)
4. table: 서류 결정과 평가 총점을 나란히 (두 전형이 엇갈리는 지원자가 보이게)
5. evidence: 평가 확인할 점, 다음 전형에서 확인할 점

## 요약에 담을 것

영역별로 강하거나 약했던 곳, 서류와 평가가 엇갈린 지원자, 면접에서 확인할 점.
